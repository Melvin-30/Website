SOP 5: Use of Audio on web pages using HTML5

  • Create a webpage named audio.html to set an audio file in web page with controls such that it uses HTML5 elements. The audio file must play as soon as the webpage loads in browser and it will start over again, every time when it is completed.
  • Create another webpage named audio1.html which provides multiple source file formats for the same audio file that plays a sound with controls. The code must incorporate the list of sound files formats (like wav, MP3 or ogg etc).

Source Code: Audio.html

<!DOCTYPE html>
<html>
<head>
    <title>Audio with controls</title>
</head>
<body>
    <h1>Audio With Single Source</h1>
    <audio loop="-1" autoplay controls>
        <source src="Song.mp3" type="audio/mp3">
    </audio>
</body>
</html>

Source Code: Audio1.html

<!DOCTYPE html>
<html>
<head>
    <title>Audio with controls</title>
</head>
<body>
    <h1>Audio With Multiple Source</h1>
    list of Audio files
    <ol>
        <li>Song.mp3</li>
        <li>Song.ogg</li>
        <li>Song.wav</li>
    </ol>
    <audio autoplay controls>
        <source src="Song.mp3" type="audio/mp3">
        <source src="Song.ogg" type="audio/ogg">
        <source src="Song.wav" type="audio/wav">
        Your computer doesn't support audio file
    </audio>
</body>
</html>
