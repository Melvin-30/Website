SOP 4: Write a PHP program to store mark in an array.

SOP 4: Write a PHP program to save marks of English, Hindi, Marathi, Maths and Information Technology in an array. Display marks of individual subject along with total marks and percentage

Source Code: SOP.php

<!DOCTYPE html>
<html>
<head>
    <title>PHP program to store marks in an array</title>
</head>
<body>
    <h2>Student Marks</h2>

    <?php
    $marks = array(
        "English" => 78,
        "Hindi" => 85,
        "Marathi" => 74,
        "Maths" => 92,
        "Information Technology" => 88
    );

    echo "English : " . $marks["English"] . "<br>";
    echo "Hindi : " . $marks["Hindi"] . "<br>";
    echo "Marathi : " . $marks["Marathi"] . "<br>";
    echo "Maths : " . $marks["Maths"] . "<br>";
    echo "Information Technology : " . $marks["Information Technology"] . "<br>";

    $total = $marks["English"]+$marks["Hindi"]+$marks["Marathi"]+$marks["Maths"]+$marks["Information Technology"];

    $percentage = $total / count($marks);

    echo "<h3>Total Marks: " . $total . "</h3>";
    echo "<h3>Percentage: " . $percentage . "%</h3>";
    ?>
</body>
</html>
